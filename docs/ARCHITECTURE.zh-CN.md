# 架构说明（中文摘要）

英文设计细节与验收边界见 [ARCHITECTURE.md](ARCHITECTURE.md) 和
[ARCHITECTURE_DECISIONS.md](ARCHITECTURE_DECISIONS.md)。本文只说明整体形状，
不重复协议字段。

## 一个服务、一个存储、按需引擎

- 客户端通过 stdio 连接一个本地 MCP 服务。
- 所有工具由同一个注册表声明和分发；工具发现返回的集合就是实际服务的集合。
- 启动时必须找到 PoB `src/`（`POB_PATH`、已安装应用或仓库内置引擎）和 LuaJIT；
  服务会打开一次引擎验证，缺失时直接退出，不提供降级运行。
- 构筑状态保存为不可变快照（SHA-256 内容寻址）。任何修改都生成子快照，
  父快照不被改写。这里的快照就是构筑版本；其中的引擎信息记录创建来源，
  不限制以后使用的引擎。更新 PoB 不改写旧文件或编号。
- 计算在独立、短生命周期的无界面 PoB 进程中完成。每次计算都从不可变快照
  加载，候选评估不会改变基准。
- 计算结果直接返回实际引擎、配置和警告；不新增计算记录仓库或升级接口。
  比较时双方使用当前引擎重新计算，运行环境不一致时不混算收益。
- 实际加载失败或已检测到的状态丢失仍会阻止操作；原始 XML 始终保留。
  当前加载校验覆盖活动天赋树的版本、节点与专精，并保留旧品质宝石的防护；
  加载成功不代表所有历史技能、词缀和配置都已得到完整兼容验证。
- Linux/macOS 使用原生系统文件锁，进程异常退出后由系统释放。
  无法确认归属的锁标记保留并提示人工处理，不跨容器猜测进程是否存活。

## 数据源分离

| 数据源 | 用途 | 边界 |
| --- | --- | --- |
| PoB 引擎 | 天赋、装备、技能、伤害和防御计算 | 使用仓库内置或用户指定的原始引擎 |
| poe.ninja | 通货和暗金参考价 | 带赛季和时间戳，不是可成交价格 |
| 官方国际服交易 | 实时挂牌查询 | 默认 `securable` + 明确标价；区分一口价和要价 |

交易估价不会自动回退到 poe.ninja 参考价，参考价也不会被描述成可执行利润。

## 结果约定

- 缺失值保持 `unknown`，不写成 0。
- 启发式建议标注为未验证，并列出输入。
- 有界采样说明上限，不声称完整。
- 每个结果携带引擎身份和快照 ID，便于复核。

## 目录

| 路径 | 内容 |
| --- | --- |
| `packages/pob-mcp/src/index.ts` | 服务入口和组合根 |
| `src/foundation/` | 快照、任务、求值和历史 |
| `src/features/` | 各工具的业务实现 |
| `src/domain/` | 纯规则和查询构造 |
| `src/ports/`、`src/adapters/` | 引擎、交易、行情、修正数据的端口与适配 |
| `lua/vanilla_stdio_bridge.lua` | 无界面引擎的 stdio 适配层 |

## 验证

在仓库根目录运行 `npm run validate`：构建、全量 Jest、插件元数据和 shell
语法检查。真实引擎行为由 `packages/pob-mcp/tests/smoke/` 覆盖，固定数值
基线在 `packages/pob-mcp/scripts/engine-regression.mjs`。通过测试不等于所有
构筑、机制或市场结果都正确，具体限制随结果一起返回。
各项能力与对应测试见 [FEATURE_ACCEPTANCE.md](FEATURE_ACCEPTANCE.md)。
